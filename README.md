# Repaso de Visión Artificial

Laboratorios interactivos, simulacros y ejercicios para repasar el ramo de Visión Artificial.
Se abren en el navegador, también en el celular: https://e-guajardo-s.github.io/repaso-vision/

Material de estudio **no oficial**, hecho por un alumno a partir de las clases y las diapositivas.
Puede tener errores; ante la duda, manda el material del curso.
